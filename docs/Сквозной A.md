Задача:
1. Симулятор сети в памяти: задержка, потери, разрывы, разделения, типы NAT (на уровне модели). Детерминированный режим по seed — для sync, групп, выборов.
2. Docker-стенд для реальных WebRTC-тестов: контейнеры-клиенты за разными NAT (iptables: full-cone, symmetric), эмуляция потерь и задержек через tc/netem; публичный STUN и fake-реле внутри стенда.
3. CI-матрица: unit (все пакеты), web (Chrome headless), интеграция на стенде, сборки под три платформы.
4. Метрики качества звонка для сравнения версий: потери, jitter, время установления, время восстановления.

Приёмка: сценарий «симметричный NAT у обоих → прямой путь не установился → путь через общего соседа» воспроизводится автоматически.
