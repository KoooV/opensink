Слой: core_sync.

Сначала design doc: сравни (а) хэш-цепочки по автору + сводки по диапазонам, (б) DAG с parent-хэшами, (в) range-based set reconciliation. Выбери один, обоснуй.

Задача:
1. Hybrid Logical Clock, id события = хэш.
2. Конвейер приёма: размер → подпись → членство автора в группе на момент события → дедуп → запись.
3. Anti-entropy: при появлении линка обмен сводками, догрузка недостающего пачками с backpressure.
4. Gossip новых событий соседям с дедупликацией и защитой от штормов.
5. Приоритетная загрузка: сначала последние N сообщений канала, остальная история лениво.
6. Правки/удаления как отдельные события (tombstones), не мутация.

Тесты: property-based — N реплик, случайный порядок доставки, случайные разделения сети; в конце все реплики имеют идентичное состояние. Детерминированный симулятор с seed.
Приёмка: тест сходимости на 1000 прогонов без расхождений.
