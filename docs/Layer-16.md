Слой: apps/app, интерфейс.

Задача:
1. Экраны: онбординг (создание identity, резервная копия), список групп, чат канала, список каналов, панель голосового канала, просмотр демонстрации экрана, участники и роли, приглашения, настройки (релеи, STUN, режим ретранслятора, постоянное соединение, устройства), экран диагностики сети.
2. Индикаторы пути соединения для каждого пира: прямой / через релей / офлайн; индикатор «хостит: X» в звонке.
3. Адаптивность: десктоп — три колонки; мобильный — нижняя навигация и выдвижные панели.
4. Riverpod, UI общается только с доменными сервисами. Локализация ru/en, тёмная и светлая темы, базовая доступность (семантика, фокус, контраст).
5. Честные состояния: «ждём онлайн-участника для синхронизации», «сообщение не доставлено никому», «нет прямого соединения, идёт через X».

Приёмка: сценарии «создать группу → пригласить → чат → звонок → экран» проходят в интеграционных тестах на всех трёх платформах.
