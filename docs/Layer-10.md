Слой: прикладные сервисы чата (core_domain + core_sync).

Задача:
1. ChatService: отправка, ответ, правка, удаление, реакции, упоминания, read markers. Всё через подписанные события слоя 7. Typing и presence — эфемерные, в лог не пишутся.
2. FileTransferService: чанки (например, 16 КБ), хэш-дерево (проверка каждого чанка), докачка, backpressure, источник — любой пир, имеющий блоб (скачивание с нескольких пиров параллельно), превью/миниатюры для изображений.
3. PresenceService: online/idle/dnd, «сейчас в голосовом канале».
4. NotificationService — интерфейс; реализации в платформенных слоях.
5. Лимиты размеров, квоты хранилища, защита от спама (rate limit по автору).

Приёмка: сценарный интеграционный тест на 3 пиров: сообщения, правка, удаление, передача файла 50 МБ с проверкой целостности и докачкой после обрыва.
